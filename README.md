# Rusty Bits
A collection of rust projects not worthy of a separate repo for various reasons. For example the project was a part of the tutorial/book etc or the projects is a dummy project used as a proof of concept for something bigger and/or more complicated.

## Projects
- `axum_api` - A test to-do list api written using axum. Tutorial project from [this book](https://rust-api.dev/)
- `bevy_test` - A minimal bevy setup. Tutorial project for [bevy quick start guide](https://bevy.org/learn/quick-start/introduction/)
- `ratatui-counter-app` - A simple counter app using the [ratatui couter app tutorial](https://ratatui.rs/tutorials/counter-app/)
- `ratatui-json-editor` - Json key value editor using the [ratatui json editor tutorial](https://ratatui.rs/tutorials/json-editor/)
